# ArchiveDesk V1.0.1

## English

A Windows startup compatibility update for ArchiveDesk.

### Added
- Bundled Node.js v22.23.3 x64 and its license in the Windows ZIP
- Release checks for native modules and startup without Node.js on the system PATH
- Bilingual quick-start instructions

### Fixed
- Fixed startup failures caused by a mismatch between the system Node.js version and the bundled better-sqlite3 native module
- Keep the console open after startup failures so the error can be read

### Changed
- The release launcher uses the bundled runtime directly
- The source launcher downloads and verifies the matching runtime on first use, then reuses its local cache

### Getting Started
1. Download and fully extract `ArchiveDesk-v1.0.1-win.zip`
2. Use Windows 10/11 x64; Node.js and npm do not need to be installed separately
3. Double-click `start.bat` and wait for the browser to open
4. If needed, open `http://localhost:3000` manually and keep the console open while using the app

### Known Limitations
- Complex DOCX layouts may look slightly different from Microsoft Word when rendered in the browser
- Port 3000 must be available
- The production dependency audit reports 4 unresolved issues: 1 high, 2 moderate, and 1 low, affecting sharp, morgan, qs, and body-parser. This release addresses runtime packaging and startup compatibility

## 简体中文

ArchiveDesk Windows 启动兼容性更新。

### 新增
- Windows ZIP 内置 Node.js v22.23.3 x64 及其许可证
- 增加原生模块检查，以及系统 PATH 中没有 Node.js 时的发行包启动验证
- 中英文快速启动说明

### 修复
- 修复系统 Node.js 版本与内置 better-sqlite3 原生模块不匹配导致的启动失败
- 启动失败后保留控制台，便于查看错误信息

### 变更
- 发行版启动脚本直接使用内置运行环境
- 源码启动脚本首次运行时自动下载并校验匹配的运行环境，后续复用本地缓存

### 使用方法
1. 下载并完整解压 `ArchiveDesk-v1.0.1-win.zip`
2. 使用 Windows 10/11 x64，无需另行安装 Node.js 或 npm
3. 双击 `start.bat`，等待浏览器自动打开
4. 如未自动打开，可手动访问 `http://localhost:3000`；使用期间请保持控制台打开

### 已知限制
- 复杂 DOCX 排版在浏览器中的效果可能与 Microsoft Word 略有差异
- 端口 3000 需要可用
- 生产依赖审计仍报告 4 项未解决问题：1 项高危、2 项中危、1 项低危，涉及 sharp、morgan、qs 和 body-parser。本版处理运行环境打包与启动兼容性
